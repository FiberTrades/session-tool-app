Before you generate a code

  • Wait until they've set their display name. The code is built from their profile name in the app. Generate it too early and it falls back to their email prefix — contact@… becomes CON-ST10.
  • Names under three letters fall back to random. Anything shorter after stripping non-letters gives ST10-XXXX instead of initials. Ask them to lengthen it first.
  • Accents fold correctly. "Ángel" gives ANG, so a Spanish creator gets a code they can dictate on camera.
  • Codes are refused on accounts that already pay. An existing subscriber can't redeem, so aim it at people who haven't signed up yet.
  • Don't invite negotiation. The closing line asks for a next step, not for feedback on the terms — if someone asks for a better rate anyway, you're declining a request you didn't solicit.
